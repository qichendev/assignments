# Resume Evaluation Rubric

## Overview

This rubric provides a comprehensive evaluation framework for assessing resume quality across multiple criteria.

## Evaluation Criteria

| Criteria | Excellent | Satisfactory | Non-Competitive | Needs Improvement |
|----------|-----------|--------------|-----------------|-------------------|
| **Overall Impact** | Resume should effectively land you an interview. | Resume could land you an interview. | Resume is average, needs some work to grab attention. | Resume needs significant improvement. Would not be selected for an interview. |

## Detailed Assessment

### 1. Format and Appearance

| Level | Description |
|-------|-------------|
| **Excellent** | • The resume fills the space but is also not overcrowded<br>• Resume is well organized into logical sections<br>• The information is listed in reverse chronological order and includes dates of participation<br>• Resume is pleasing to the eye |
| **Satisfactory** | • The resume almost fills the page but has some uneven white space<br>• Uses bullets to ease scanning<br>• Style is creative and stands out |
| **Non-Competitive** | • The font and spacing are not appealing and easily scanned<br>• Inconsistent formatting<br>• Descriptions are presented in paragraph form<br>• Key information is not highlighted |
| **Needs Improvement** | • There is an abundance of white space OR resume appears too crowded<br>• Poor formatting<br>• Categories don't define themselves<br>• Organization is difficult to follow |

### 2. Skills Summary

| Level | Description |
|-------|-------------|
| **Excellent** | • The skills listed are relevant and include technical skills related to your program<br>• Relevant soft skills are also listed<br>• Section is organized and easy to understand<br>• Level of proficiency is indicated |
| **Satisfactory** | • At least 3 program specific skills are listed along with related soft skills<br>• Technical experience is highlighted and is listed first |
| **Non-Competitive** | • Skills are not listed in relevant order<br>• Skills are not clearly relevant to the position/field<br>• Proficiency levels are not expressed<br>• Skills do not include program specific skills |
| **Needs Improvement** | • The section is not well defined<br>• Skills are not listed<br>• Skills are not relevant to the position/field |

### 3. Education Section

| Level | Description |
|-------|-------------|
| **Excellent** | • Each institution listed includes the name of program, location, graduation date<br>• Listed in reverse chronological order<br>• The section is well organized; formatting is consistent<br>• Also includes "extra" information such as GPA |
| **Satisfactory** | • Each institution listed includes the name of program, location, and graduation date<br>• Listed in reverse chronological order |
| **Non-Competitive** | • Programs listed in reverse chronological order, but information listed is incomplete<br>• The section is not well organized, and the format is not consistent |
| **Needs Improvement** | • The section is not well defined<br>• Crucial information is missing (no dates, no location, program is abbreviated)<br>• No order to how information is formatted |

### 4. Experience Section

| Level | Description |
|-------|-------------|
| **Excellent** | • This section is well defined, and information relates to the intended career field<br>• Places of work, location, titles, and dates are included for each position<br>• Descriptions are clear and bullets begin with a strong action verb<br>• Experience is relevant and keywords and transferable skills are included |
| **Satisfactory** | • Reverse chronological order is used<br>• Information is well defined and includes organization name, position, location, and dates<br>• Descriptions are clear but not detailed enough to fully understand what was done and accomplishments |
| **Non-Competitive** | • Reverse chronological order is used<br>• Description of experience is not detailed<br>• Experience is limited or not relevant to the field<br>• The section is not well organized, and the format is not consistent |
| **Needs Improvement** | • Reverse chronological order is not used<br>• Employment information is missing<br>• Action verbs are not used<br>• Bullets are not used<br>• Experience is not relevant<br>• This section is not well defined, and descriptions offer no illustration of what was done |

### 5. Overall Content and Relevancy

| Level | Description |
|-------|-------------|
| **Excellent** | • Objective or professional summary is targeted to the job/field<br>• Contact information is updated, appropriate and professional<br>• Verb tenses are consistent<br>• Most relevant information appears first<br>• Additional sections are appropriate and add to the resume |
| **Satisfactory** | • Resume is targeted to a specific role/industry<br>• "References available upon request" is stated<br>• Relevant skills and experience are highlighted |
| **Non-Competitive** | • Information has multiple errors<br>• Relevant experience is not easily identified<br>• Resume lacks focus<br>• Resume lacks marketability |
| **Needs Improvement** | • Minimal, generic details are used<br>• No objective or professional profile statement<br>• Information does not match up with desired position/field |

### 6. Spelling and Grammar

| Level | Description |
|-------|-------------|
| **Excellent** | • There are no spelling or grammar errors<br>• The resume can easily be scanned |
| **Satisfactory** | • Minimal (1 or 2) spelling or grammar errors |
| **Non-Competitive** | • There are more than 3 spelling or grammar errors |
| **Needs Improvement** | • There are multiple spelling and grammar errors |

---

## Usage Notes

- **Excellent**: Resume meets or exceeds all criteria and demonstrates professional quality
- **Satisfactory**: Resume meets most criteria with minor areas for improvement
- **Non-Competitive**: Resume has several areas that need attention to be competitive
- **Needs Improvement**: Resume requires significant work to meet basic standards

*This rubric should be used consistently across all resume evaluations to ensure fair and objective assessment.*
