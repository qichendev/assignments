# Final Advanced Python Project/Assignment

## Objective

Build a useful Python desktop Weather App that also displays the Date and Time. This project demonstrates the use of GUIs, Web APIs in Python, and the Python Standard Libraries.

The application will use the **OpenWeather API**.

## GUI Framework Options

You can use any Python GUI system you wish to display the weather and clocks, such as:

- **PyQt**
- **FreeSimpleGUI**
- **Tkinter**

## Requirements

### Core Functionality

1. **Configuration Management**
   - Fetch the city name and weather fetch interval (n in minutes) from a configuration file
   - Supported formats: YAML, INI, JSON, or text file

2. **Dependencies**
   - Use a `requirements.txt` file for project dependencies

3. **Weather Updates**
   - Weather must update every n minutes
   - Display a countdown clock showing when the next fetch will occur
   - App must display weather, date, and time upon startup

4. **User Interface**
   - User should be able to position the app anywhere on the screen
   - App should be minimizable to the taskbar

### Display Requirements

1. **Temperature Display**
   - Display temperature for the selected city in a large font
   - Show both Celsius and Fahrenheit
   - Use the Celsius symbol (°C) for formatting

2. **Clock and Date**
   - Display a clock that updates every second
   - Show current date and time

3. **Weather Information**
   - Display other weather conditions (Clouds, Wind Speed, etc.)
   - Include an icon representing the weather conditions
