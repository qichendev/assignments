# ⏱️ Stopwatch Application Assignment

## 📋 Assignment Specification

### 🎯 Objective

Create a useful **Stopwatch Application** using Python's Tkinter library that displays the current date and time, along with a stopwatch feature. The application should have a visually appealing interface with distinct panels and buttons.

---

## 📋 Requirements

### 🖥️ User Interface

- ✅ Use **Tkinter** to create the GUI
- ✅ Display the current date and time
- ✅ Create two adjoining panels:
  - One for the current time
  - One for the stopwatch
- ✅ Each panel should have a different background color and be visually appealing
- ✅ Stopwatch time should be displayed in a larger font size with distinct colors
- ✅ Include buttons for:
  - 🟢 **Start**
  - 🔴 **Stop** 
  - 🟡 **Pause**
- ✅ Buttons should have different colors and styles to enhance aesthetics
- ✅ Ensure the application is scalable and maintains its layout when resized

### ⚙️ Functionality

- ✅ Stopwatch starts counting when **Start** button is pressed
- ✅ Stopwatch stops counting when **Stop** button is pressed
- ✅ Stopwatch pauses when **Pause** button is pressed and resumes when **Start** is pressed again
- ✅ Current date and time updates every second

### 🚀 Additional Features (Optional)

- ✅ Add a reset button to reset the stopwatch
- ✅ Allow user to switch between 12-hour and 24-hour formats for time display

---
The window is titled **"Stopwatch Application"** and has two horizontal panels:

### 📅 Top Panel
- **Background**: Light blue
- **Content**: Date and time display
- **Format**: `2025-08-04 18:38:26`

### ⏱️ Middle Panel  
- **Background**: Light green
- **Content**: Stopwatch time in large, red font
- **Format**: `00:00:00`

### 🔘 Bottom Section
Four colored buttons:
- 🟢 **Start** (Green)
- 🔴 **Stop** (Red) 
- 🟡 **Pause** (Yellow)
- 🟠 **Reset** (Orange)
