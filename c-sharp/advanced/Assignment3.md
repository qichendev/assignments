# Assignment 3 - CSD-3353 Web Applications in C#.NET

## Assignment (15%)

### Secure Movies API - MongoDB + JWT Auth

Convert your movies project backend to use MongoDB Atlas and secure API endpoints using JWT-based authentication.

## Course Learning Outcomes (CLOs)

- CLO 3: Implement NoSQL persistence using MongoDB
- CLO 4: Apply authentication and authorization using JWT

## Requirements

- Switch database to MongoDB Atlas
- Add user registration and login endpoints
- Protect movie API with `[Authorize]` and JWT Bearer tokens
- Provide sample frontend HTML forms for login/register and calling protected API endpoints
- Ensure that your MongoDB Atlas cluster allows access from all IP addresses (`0.0.0.0/0`)

## Deliverables

- Zipped authenticated API project with MongoDB integration
- Word document showing token generation, usage, and screenshots of functionality
- MongoDB setup explanation including IP access rule

## How to Submit Your Assessment

Submit a zipped folder with the project files and a Word document with screenshots and setup instructions to D2L Dropbox.
