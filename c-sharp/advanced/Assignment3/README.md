# Assignment 2 – CSD-3353 Web Applications in C#.NET

**Assignment (15%)**

**Enhanced Movies Manager – EF Core + API + Validation**

Extend Assignment 1 by integrating EF Core with SQLite, adding form validation, and exposing a RESTful API for the movie data.

## Course Learning Outcomes (CLOs)

- **CLO 2:** Develop RESTful APIs
- **CLO 3:** Implement SQL-based persistence using Entity Framework Core

## Requirements

- Start with Assignment 1 code as base
- Add client-side and server-side form validation
- Connect to SQLite via Entity Framework Core (Code-First + Migrations)
- Expose RESTful API endpoints: GET, POST, PUT, DELETE
- Test API using Swagger and Postman

## Deliverables

- Zipped updated project folder with DB integration
- Word document with DB setup, API instructions, and screenshots of functionality
- Swagger or Postman screenshots

## How to Submit Your Assessment

Submit a zipped folder with the project files and a Word document with screenshots and setup instructions to D2L Dropbox.
