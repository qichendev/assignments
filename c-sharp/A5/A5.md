# Assignment 05: Rebel Alliance Roster System

## Overview
Practice designing and implementing abstract classes and inheritance

- Use protected and private properties appropriately
- Create and override class methods including `ToString()` and `Equals()`
- Work with lists of polymorphic objects
- Design simple class hierarchies

## Part 01: Class Design

### Abstract Class: Rebel
This is the base class representing a general Rebel Alliance operative. It includes the following:

#### Protected Properties (5 total):
- `string Name`
- `string Species`
- `string Homeworld`
- `string Rank`
- `int MissionsCompleted`

#### Public Members:
- Getters and Setters for all 5 properties
- `ToString()` override to return a description
- `Equals(object obj)` override to compare Rebels by Name and Homeworld

### Subclasses

#### 1. Spy
**New Private Properties:**
- `int StealthLevel`
- `bool IsUndercover`

**Constructor and one method:**
- `GetIntelReport()` - returns a string based on stealth level and undercover status

#### 2. Pilot
**New Private Properties:**
- `string StarfighterModel`
- `int FlightHours`

**Method:**
- `FlyMission()` - returns a string about the mission based on hours flown and fighter model

#### 3. Jedi
**New Private Properties:**
- `string LightsaberColor`
- `bool IsCouncilMember`

**Method:**
- `UseTheForce()` - returns a string based on whether they're a council member and what their saber color is

## Part 02: Main Method Task - Assemble the Team

You have been given a list of 4 Rebel operatives:

```csharp
{
    new Spy("Cassian Andor", "Human", "Fest", 32, 15, true),
    new Pilot("Wedge Antilles", "Human", "Corellia", 28, 24, "X-Wing"),
    new Jedi("Luke Skywalker", "Human", "Tatooine", 25, 30, "Green"),
    new Pilot("Hera Syndulla", "Twi'lek", "Ryloth", 35, 40, "Ghost")
};
```

### Task:
1. Add these objects to a `List<Rebel>`
2. Loop through the list and call `ToString()` on each one
3. Use `Equals()` to compare two operatives for duplication
4. Display a summary of:
   - Total number of missions completed by all Rebels
   - How many of each type (Spy, Pilot, Jedi)
