# P0901 Statement Trigger

## Step 1: Create Log Table

Create a LOG table called **GL_PRO_AUDIT_LOG** to capture the audit trail of changes to the GL_PROFESSORS_COPY table. The table will contain the following columns:

| Column | Type | Default |
|---|---|---|
| user_id | VARCHAR2(30) | DEFAULT USER |
| last_change_date | DATE | DEFAULT SYSDATE |
| trigger_name | VARCHAR2(50) | |
| log_action | VARCHAR2(30) | |

## Step 2: Create Statement-Level Trigger GL_PROFESSOR_TRG

Create a statement-level trigger called **GL_PROFESSOR_TRG** that inserts a row into the GL_PRO_AUDIT_LOG after one or more rows are added to the GL_PROFESSORS_COPY table. The GL_PRO_AUDIT_LOG rows should contain the value gl_professor_trg in the trigger_name column and **INSERT** in the log_action column. The user_id and last_change_date columns will contain default values.

## Step 3: Test the GL_PROFESSOR_TRG Trigger

- Create an anonymous block that inserts a row into the gl_professors_copy table.
- Use bind/host variables to prompt for the input data.
- Allow for mixed case when entering the school code.
- Allow for mixed case when entering the first and last names and format names with first character in upper case and the remaining character in lower case.
- Call the ADD_PROFESSOR procedure created in chapter 6 to add the professor into the GL_PROFESSORS_COPY table.
- Display the output as shown.
- Include an EXCEPTION section that handles duplicate professor number errors and catch-all errors.
- Run the block three times to insert the following rows into the table:
