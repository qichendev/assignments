# Chapter 4 - Cursors Programming Exercises

## P0402: Professor Teaching Load

Create an anonymous block that displays the teaching load for a professor by displaying a list of courses assigned to the professor for a given term.

### Requirements

- In the example below, the list of courses being taught by **Olivia Smith** for the **winter 2021** term is listed.
- Allow for upper and lower case for semester term.
- Use a **cursor FOR LOOP**.
- Use **%TYPE**, **user type record structure**, and **%ROWTYPE** where appropriate.
- Pass the parameters to the cursor.

### Input

- `:ENTER_SEMESTER_YEAR` (e.g., 2021)
- `:ENTER_SEMESTER_TERM` (e.g., W)
- `:ENTER_PROFESSOR_NO` (e.g., 5001)

### Expected Output Format

```text
Teaching Load for Olivia Smith
-------------------------------------------
Semester: 2021W

Course(s)                Section(s)
---------                ----------
Database Design & SQL    10009
Web Technologies I       10001
Web Technologies II      10005
```

## P0403: Class List

Create an anonymous block that displays a class list for a specific section.

### Requirements

- Use a **cursor FOR LOOP**.
- Use **%TYPE**, **user type record structure**, and **%ROWTYPE** where appropriate.
- Pass the parameter to the cursor.

### Input

- `:ENTER_SECTION_ID` (e.g., 10001)

### Expected Output Format

```text
Class List for CIS100 Web Technologies I
Semester: 2021W
Instructor: Olivia Smith

Student No     Student Name
----------     ------------
1000           Meagan Farenden
1001           Elianora Ponsford
1002           Kristina Littefair
1003           Dalis Filchagin
1004           Corrinne Wooder
```
