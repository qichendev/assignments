## PO802 Donor overload application

- Create an overload package that accesses the DONORS table by donor id or registration number.
- Create two anonymous blocks that prompt for donor id and registration number and display the donor information as shown.

**Input:**

`:ENTER_DONOR    1`

**Output:**

    Donor name: Jake Smith
    Donor type: I
    Pledge amount: $23.00
    Pledge months: 24
    Total amounts: $552.00

Donor request by donor id completed

**Input:**

`:ENTER_REGISTRATION_CODE    G1002`

**Output:**

    Donor name: Sally Donor
    Donor type: G
    Pledge amount: $15.00
    Pledge months: 24
    Total amounts: $360.00

Donor request by registration code completed

**Input:**

`:ENTER_DONOR_ID    99`

**Output:**

Donor not found

## PO803 Bodiless Package for Currency Exchange

- Create a package called `currency_exchange_pkg` that assigns literal values for currency exchange rates between the counties listed below.

| Exchange Type | From Country  | To Country     | Conversion rate |
|---|---|---|---|
| 1 | United States | Canadian      | 1.34470 |
| 2 | Canadian      | United States | 0.743731 |
| 3 | Euro          | United States | 1.06570 |
| 4 | United States | Euro          | 0.938351 |
| 5 | Euro          | Canadian      | 1.43287 |
| 6 | Canadian      | Euro          | 0.697899 |

- Create an anonymous block that prompts for exchange type and currency amount, calculates the exchange currency amount, and displays the output shown. In the example below, exchange type 1 is entered with the currency amount 1200.00. Exchange type 1 indicates that the exchange is for United States dollars to Canadian dollars. The 1200.00 United States dollars is converted to Canadian dollars using the named constant defined in the `currency_exchange_pkg` package.

**Input:**

`:ENTER_CONVERSION_TYPE    1`

`:ENTER_CURRENCY_AMOUNT    1200`

**Output:**

`$1200.00 United States dollars = $1,614.00 Canadian dollars`
