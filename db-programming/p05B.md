# P0505
Write an anonymous block:
*   Prompt for school code.
*   Try to delete the school code from the `gl_schools` table.
*   Include an `EXCEPTION` section:
    *   Define a user-defined exception that traps `NOT FOUND` errors on delete statement and raise exception.
    *   Include user-defined exception that traps a program code that is too long.
    *   Include user-defined exception that traps for foreign key errors when there are child foreign key relationships with the parent row being deleted.
    *   Trap all other errors.

---

### **Test Case 1**
**Input:**  
`:ENTER_SCHOOL_CODE XX`

**Output:**  
`School code XX does not exist.`

---

### **Test Case 2**
**Input:**  
`:ENTER_SCHOOL_CODE BUX`

**Output:**  
`School code is too long. Can only be two characters long.`

---

### **Test Case 3**
**Input:**  
`:ENTER_SCHOOL_CODE BU`

**Output:**  
`Cannot delete row because of integrity constraint error. There are child foreign key relationships with the GL_SCHOOLS table.`

# P0506
**Note:** Access the `STUDENTS` table.  
Write an anonymous block that:
*   Prompts for GPA
*   Use a `SELECT` statement to return students with a GPA greater than the GPA entered as a bind variable
*   Display as shown below
*   Include an `EXCEPTION` section:
    *   Define a predefined exception to trap `NO_DATA_FOUND` error
    *   Define a predefined error to trap `TOO_MANY_ROWS` error
    *   Trap all other errors and display `ERRCODE` and `ERRMSG`

---

### **Test Case 1**
**Input:**  
`:ENTER_GPA 3.4`

**Output:**  
`Student 1 has a GPA of 3.45`

---

### **Test Case 2**
**Input:**  
`:ENTER_GPA 2.5`

**Output:**  
`TOO MANY ROWS RETURNED FOR GPA > 2.5`

---

### **Test Case 3**
**Input:**  
`:ENTER_GPA 3.5`

**Output:**  
`NO DATA FOUND FOR GPA > 3.5`
