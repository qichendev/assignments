# P0904 INSTEAD OF Trigger

## Step 1: Set-up

Use the `Script_4_Reset_COPY_Tables` procedure to build/reset the copy tables. To execute this procedure, place the following at the beginning of the script:

```sql
BEGIN
    script_4_reset_copy_tables;
END;
```

## Step 2: Create View

Create a view called `professor_section_view` that generates a list of professors and the total sections each professor is assigned. List all professors even if no sections are assigned.

## Step 11: Create Trigger

Create an `INSTEAD OF` trigger called `professor_section_delete_trg` that deletes a professor from the `gl_professors_copy` table and deletes any sections assigned to that professor from the `gl_sections_copy` table.

## Step 13: Delete Professor
