# P0801 College Package

## Step 1

Use `Script_4_Reset_COPY_Tables` to create or reset the `GL_PROFESSORS_COPY` table.

## Step 2

Create the package specification and package body for a package called `college_pkg` that contains three procedures:

- `get_professor`
- `add_professor`
- `delete_professor`

These procedures are added to the package body one at a time for easier debugging.

## Step 3

Add the `get_professor` procedure to the package.

- Pass professor number as an `IN` parameter.
- Define a user-defined record structure as an `OUT` parameter that returns the professor data to the calling environment. Hint: Use `%ROWTYPE`.
- No exception section in this procedure. Errors are handled in the calling environment.

## Step 4

Create an anonymous block to test the `get_professor` procedure.

- Call the `get_professor` procedure using a bind variable to input the professor number and send as an `IN` parameter.
- The `get_professor` procedure returns either the professor's data in a user-defined record structure or an exception error.
- If the professor data is returned, display it as shown.
- Include an exception section to handle an error when the professor is not found, as shown.

### Input (valid professor)

```text
:ENTER_PROFESSOR_NO  5001
```

### Output

```text
No: 5001
Name: Olivia Smith
Office ext: 3864
Office no: 301
```

### Input (professor not found)

```text
:ENTER_PROFESSOR_NO  9999
```

### Output

```text
Professor 9999 does not exist in the professor's table
```

## Step 5

Add the `add_professor` procedure to the `college_pkg` package.

- Pass professor number, first name, last name, office ext., and office number as `IN` parameters.
- Insert a new row into the professor's table.
- If the insert is successful, output the new professor as shown.
- If the insert is not successful, an exception occurs and returns to the calling environment. The exception is handled in the calling environment.
- No exception section in this procedure. Errors are handled in the calling environment.

## Step 6

Create an anonymous block to test the `add_professor` procedure.

- Call the `add_professor` procedure, sending professor number, first name, last name, office ext., and office number as parameters.
- Include an exception section to handle an error when the professor is already in the table, as shown below.

### Input (new professor)

```text
:ENTER_PROFESSOR_NO  2001
:ENTER_FIRST_NAME    Pete
:ENTER_LAST_NAME     Smith
:ENTER_OFFICE_EXT    2201
:ENTER_OFFICE_NO     201
```

### Output

```text
Inserted 1 row

Professor: 2001 - Pete Smith
Office ext.: 2201
Office no: 201
```

### Input (duplicate professor)

```text
:ENTER_PROFESSOR_NO  2001
:ENTER_FIRST_NAME    Jack
:ENTER_LAST_NAME     Milton
:ENTER_OFFICE_EXT    2210
:ENTER_OFFICE_NO     210
```

### Output

```text
Professor 2001 already exists in the professors table
```

## Step 7

Add the `delete_professor` procedure to the `college_pkg` package.

- Pass professor number as an `IN` parameter.
- Delete the row for the professor.
- No exception section in this procedure. Errors are handled in the calling environment.

## Step 8

Create an anonymous block to test the `delete_professor` procedure.

- Call the `delete_professor` procedure, sending the professor number as an `IN` parameter.
- The `delete_professor` procedure will return the number of rows deleted in the `SQL%ROWCOUNT` attribute.
- If the count is zero, raise the `NO_DATA_FOUND` error.
- Include an exception section to handle the `NO_DATA_FOUND` error, as shown below.

### Input (duplicate professor)

```text
:ENTER_PROFESSOR_NO  2001
```

### Output

```text
Delete professor request completed
```

### Input (not found)

```text
:ENTER_PROFESSOR_NO  2001
```

### Output

```text
Professor 2001 does not exist in the professors table
```
