# Final Full-Stack (MERN) JavaScript Project

Using Node.js with Express, Mongoose, React, and MongoDB, create a user website that is a CRUD application and exposes a REST API. You may use your Express project as the backend server.

## Minimum Data Requirements

The application must manage the following user data at minimum:

- Last name
- First name
- Date of birth
- Address 1
- Address 2
- City
- Postal code
- Country
- Phone number
- Email
- User notes

## Data Population

Populate the MongoDB database with random data. See:

- <https://jsonplaceholder.typicode.com/>
- <https://github.com/jdorfman/awesome-json-datasets>

## Application Requirements

The data should be collected by a React web form and must use HTTP methods to update the database.

Use Axios, if you wish, to fetch the backend data:

- <https://www.geeksforgeeks.org/reactjs/axios-in-react-a-guide-for-beginners/>

The web application should have three pages:

1. A page to add data.
2. A page to update data.
3. A page to display the data in a table.

Add a delete button on the update page to delete a user.

Use React to create:

- A simple login page.
- A grid page to display data.

React data grid resource:

- <https://www.ag-grid.com/react-data-grid/getting-started/>

Try the free Evergreen React components to enhance your pages:

- <https://evergreen.segment.com/components>

Add CSS to make your components and project shine.

Use one of the following to format the page and add menus and toolbars:

- W3CSS: <https://www.w3schools.com/w3css/>
- Bootstrap: <https://react-bootstrap.netlify.app/>

## Documentation Requirements

Documentation is key. Lack of adequate comments will reduce your points.

## Instruction Checklist

1. Add a checklist of tasks and show your planning in Markdown format. Do not use `.docx` or `.pdf` files.
2. Add a header comment in your main `index.js` file with your name and CNumber. The more comments you add, the better your chances of earning extra points. Annotate your React code heavily so that it is totally clear.
3. Add screenshots for each web page to prove that your code works.
4. Create and include a basic user manual on how to use your creation. Use `.md` format.
5. Zip your assignment and name it with your CNumber before submitting it to the specified Dropbox. Do not submit `.rar`, `.7zip`, or any other compressed file format. Do not send your `node_modules` directories. They can be recreated from `package.json` using `npm`.

Failing to follow these instructions will lead to points being subtracted.
